# Tic-Tac-Toe

A clean, browser-based Tic-Tac-Toe game built with vanilla JavaScript.

## Features

- Two-player gameplay
- Score tracking
- Turn indicator
- Auto-reset after each game
- Manual reset button
- Responsive design

## How to Play

### Local

1. Execute `git clone <git@github.com>:Ray-AS/tic-tac-toe.git` in desired folder to download project
2. Open `index.html` in your browser
3. Players take turns clicking empty cells
4. First player to get three in a row wins
5. Scores are tracked automatically

## Files

- `index.html` - Main HTML structure
- `client.js` - Game logic
- `styles.css` - Styling

## Tech Stack

- HTML
- CSS
- JavaScript (Module Pattern)
